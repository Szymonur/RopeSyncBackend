# 🧗‍♂️ RopeSync - Backend REST API

The backend powering the RopeSync mobile app. It is responsible for handling user authentication, managing the climbing route database, the social system (following users), and persisting statistics and telemetry data from hardware devices. Built with a strong focus on data security and performance.

## ✨ API Features

* **Authentication (JWT):** Generation and verification of Access and Refresh tokens. Passwords are securely hashed using the modern Argon2 algorithm.
* **User Management:** Registration and login flows.
* **Password Reset:** Generates secure, expiring tokens and sends email notifications with reset links.
* **Community:** Endpoints for following other users and fetching aggregated activity feeds.
* **Route Database:** API for querying regions, sectors, and climbing routes.
* **Ascents & Statistics:** Persists both manual ascent logs and hardware-enriched data (ESP32 telemetry including falls and clips) to user profiles.

## 🛠 Tech Stack

* **Environment:** Node.js with TypeScript (tsx / ts-node)
* **Framework:** Express.js (v5)
* **Database:** PostgreSQL (using the raw `pg` driver)
* **Authentication & Cryptography:** JSON Web Tokens (JWT), Argon2
* **Mailing:** Nodemailer
* **Security Middleware:**
  * **Helmet:** Secures HTTP headers.
  * **CORS:** Restricts cross-origin resource sharing.
  * **Express Rate Limit:** Protects against brute-force and DDoS attacks.
  * **XSS Clean & HPP:** Input sanitization to prevent Cross-Site Scripting and HTTP Parameter Pollution.
* **API Documentation:** Swagger (swagger-jsdoc & swagger-ui-express)

## 🚀 Getting Started

### Prerequisites
* Node.js
* PostgreSQL (running locally or via Docker)

   ```bash
   git clone https://github.com/Szymonur/RopeSyncBackend.git
   cd RopeSyncBackend
   npm install
   ```

3. Start the Database (Docker):
    Spin up the PostgreSQL container in the background using Docker Compose:
   ```bash

   ```

   ```bash
   npm run db:init
   npm run db:seed
   ```

4. Start the development server:  
   ```bash
   npm run dev
   ```
